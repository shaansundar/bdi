# bdi

A one-question-at-a-time calculator for the 21-item Beck Depression Inventory self-scoring questionnaire.

Live: https://shaansundar.github.io/bdi/

- Scroll, swipe, or use the up and down arrow keys to move between questions. Press 0 to 3 to answer.
- Your total (0 to 63) and score band appear after the last question.
- Everything runs in the browser. Nothing is sent or stored.

This is a self-scoring screening tool, not a diagnosis. It is an unofficial page, not affiliated with the publishers or rights holders of the Beck Depression Inventory. If you are struggling, please talk to a doctor or mental health professional.

It is a single file: `index.html`.
